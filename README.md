# GoMarket

> **Full-Stack E-Commerce Store with Go & Svelte**

[![Go Version](https://img.shields.io/badge/Go-1.22-00ADD8?style=flat&logo=go)](https://go.dev/)
[![Svelte](https://img.shields.io/badge/Svelte-Framework-FF3E00?style=flat&logo=svelte)](https://svelte.dev/)
[![TailwindCSS](https://img.shields.io/badge/TailwindCSS-UI-38B2AC?style=flat&logo=tailwind-css)](https://tailwindcss.com/)

GoMarket is a fast and responsive online storefront featuring a high-concurrency Go REST API backend and a reactive Svelte user interface.

---

## ⚡ Tech Stack

- **Backend:** Go 1.22, REST API architecture
- **Frontend:** Svelte, JavaScript, TailwindCSS, PostCSS, Rollup / Vite
- **Storage:** Relational schema for products, categories, cart sessions, and orders

---

## 🚀 Key Features

- **Product Catalog:** Category filtering, keyword search, and stock indicators.
- **Cart & Order Flow:** Persistent shopping cart state with instant quantity updates.
- **Responsive Checkout:** Clean, modern interface optimized for mobile and desktop screens.
- **Lightweight Footprint:** Highly optimized bundle size powered by Svelte compiler.

---

## 🚦 Quick Start

```bash
# Clone repository
git clone https://github.com/RisenSamurai/GoMarket.git
cd GoMarket

# 1. Run Backend
go run main.go

# 2. Run Frontend
npm install
npm run dev
```
